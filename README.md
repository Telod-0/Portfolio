# Portfolio — Alessio Provenza

Sito portfolio con una selezione di progetti di product e UX/UI design.
Ogni progetto ha una pagina dedicata.

**Sito online:** <https://telod-0.github.io/Portfolio/>

## Tecnologie

- **HTML5**
- **SCSS**
- **Bootstrap 5.3**
- **JavaScript** per il form contatti
- **EmailJS** per l'invio del form contatti


### Gli stili

Il CSS è generato da `scss/style.scss`. Dopo ogni modifica va ricompilato:

Con VS Code e l'estensione **Live Sass Compiler** la compilazione
avviene al salvataggio (output `expanded` in `css/`, come da `.vscode/settings.json`).
